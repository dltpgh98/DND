# 📚 동내북 (DND)
> **새로운 기술 생태계(Kotlin + FastAPI)로의 성공적인 아키텍처 전환 프로젝트**

사용자의 취향을 분석하여 맞춤형 도서를 검색하고, 관심 있는 책을 즐겨찾기(북마크)할 수 있는 안드로이드 애플리케이션입니다. 
이전 프로젝트(CASS, BBIC)를 통해 체화했던 Java/PHP 기반의 클라이언트-서버 통신 아키텍처 경험을 바탕으로, 모던 언어인 Kotlin과 Python(FastAPI)으로 기술 스택을 전면 전환하여 '새로운 기술에 대한 빠른 적응력'과 '견고한 백엔드-프론트엔드 연동 능력'을 증명한 프로젝트입니다.

## 🛠 기술 스택 (Tech Stack)
- **Client:** Kotlin, Android (Native XML), Retrofit2
- **Backend (API):** Python, FastAPI, Uvicorn
- **Database:** MSSQL (pymssql)

<br>

## ✨ 주요 기능 (Key Features)
- **도서 검색 API 연동:** 사용자가 입력한 검색어를 바탕으로 서버에서 부분 일치(LIKE) 쿼리를 수행하여 클라이언트(RecyclerView)에 도서 목록을 동적으로 렌더링
- **북마크 및 취향 시스템:** 마음에 드는 도서를 찜하고, 해당 도서에 매핑된 태그를 사용자의 취향 데이터(Preference)에 누적하여 맞춤형 추천을 제공하는 백엔드 로직 구현

<br>

## 💡 기술적 고민

### 1. 언어/프레임워크 전환과 아키텍처의 유연성 입증
- **도전:** Java와 PHP 환경에서 벗어나, 처음으로 Kotlin(클라이언트)과 Python 기반의 FastAPI(서버)라는 새로운 기술 스택을 도입해야 했습니다.
- **해결 및 성과:** 앞선 프로젝트들에서 JSON 기반의 RESTful 통신 규격과 데이터베이스 설계의 본질을 완벽하게 이해하고 있었기에, 언어가 바뀌었음에도 흔들림 없이 Retrofit2를 활용한 비동기 통신과 MSSQL 연동 API를 빠르고 안정적으로 구축해 냈습니다. 

### 2. 한글 인코딩(Encoding) 충돌 해결
- **문제:** 파이썬 백엔드에서 MSSQL 데이터베이스의 한글 도서명과 저자명을 조회하여 클라이언트로 넘겨줄 때, 글자가 깨지는 인코딩 충돌 현상이 발생했습니다.
- **해결:** 데이터베이스의 기존 문자열 셋을 파악하고, 파이썬 코드 단에서 `.encode('ISO-8859-1').decode('cp949')` 등 바이트 단위의 디코딩 로직을 거치도록 처리하여 클라이언트에 온전한 UTF-8 형태의 JSON 데이터가 전달되도록 통신 안정성을 확보했습니다.
